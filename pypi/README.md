# awaro

This name is reserved for **Awaro**, an autonomous LoRaWAN gateway
(hardware product) — see <https://awaro.fr>.

There is no Python code here. The related open-source software lives in the
[lorawan2mqtt](https://github.com/lorawan2mqtt/lorawan2mqtt) project:
a community codec database and a LoRaWAN → MQTT / Home Assistant bridge.
